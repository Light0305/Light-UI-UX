# 05 — 3-Tier Adaptive Image Generation, Atelier Zero Optics & 6-Step Page Blending

This manual governs **when and how to generate, retrieve, analyze, and blend imagery, product plates, and IP brand symbols** using [`scripts/media_gen.py`](../scripts/media_gen.py).

## 1. The 3-Tier Adaptive Image Routing Architecture

Never use broken placeholder URLs (`unsplash.com/random`, `via.placeholder.com`, `picsum.photos`) or cheap flat CSS geometry pretending to be an illustration. Route all media needs through [`scripts/media_gen.py`](../scripts/media_gen.py):

```bash
# Check active image generation tier & configuration
python scripts/media_gen.py status
```

| Tier | Trigger Condition | Execution Mechanism |
| :--- | :--- | :--- |
| **Tier 1: Host-Native Image Generator** | An actual host image-generation tool is available. This remains the first choice even when a custom API key is configured, unless the user explicitly selects another provider. | 1. Run `python scripts/media_gen.py generate "<subject>" --mode editorial --bg-hex "#0d0e11" --calm-zone left --out ./hero.png`.<br>2. Pass the returned `positive_prompt` to the available host image tool and save to `./hero.png`.<br>3. Run `python scripts/media_gen.py analyze ./hero.png` to verify the `calm` text-overlay zone. |
| **Tier 2: User-Configured Custom API** | No host image tool is available and an API key is configured, or the user explicitly requests this API. | Use `--tier auto --host-unavailable` for fallback selection, or `--tier api` for an explicit API request. Uses Bearer authentication and the OpenAI Images generations request/response format. Native Gemini, OpenRouter chat-image, and asynchronous job protocols require separate adapters. |
| **Tier 3: Zero-Key CC0 Archive + 16 WebGL Shaders** | Offline / no image generation tool available, OR the aesthetic calls for authentic archival/museum photography or real-time procedural shaders. | • **CC0 Museum/Archive Photography**: Run `python scripts/media_gen.py generate "<query>" --tier cc0 --out ./archive.jpg` (queries Art Institute of Chicago CC0 public domain + Wikimedia Commons).<br>• **16 Single-File WebGL2 Shaders**: Run `python scripts/arsenal.py shader webgl-liquid-metal --extract ./shader.html`. |

`--tier auto` prefers the host. The calling agent must check which tools it actually has; the Python script cannot discover host capabilities. If no host image tool is available, rerun with `--host-unavailable`: a configured API is selected first, otherwise CC0 retrieval. Explicit `--tier host`, `--tier api`, or `--tier cc0` takes precedence over automatic routing. A host delegation response does not itself generate or save an image, and must not be reported as completed generation.

```bash
# Host-first, even when an API key has been configured
python scripts/media_gen.py generate "A handmade ceramic bowl on linen" --out ./bowl.png

# Calling agent has checked that no host image tool is available: API, then CC0
python scripts/media_gen.py generate "A handmade ceramic bowl on linen" --host-unavailable --out ./bowl.png
```

## 2. Atelier Zero 3-Layer Physical Optics Prompt Law

AI images look fake when prompted with UI words (`"hero banner"`, `"website background"`, `"8k masterpiece"`, `"futuristic glowing nodes"`). Every prompt generated by `media_gen.py` is constructed from **Three Physical Layers**:

1. **Layer 1 — Concrete Domain Artifact & Spatial Calm Zone**:
   - Name the exact physical material, object, or environment from the domain inventory.
   - Explicitly reserve **40%–45% of the frame as a low-contrast, out-of-focus `calm` zone** (`left`, `right`, `top`, `bottom`, or `center`) where UI typography will sit.
2. **Layer 2 — Camera, Lens & Film Stock Physics**:
   - Specify real optical hardware: e.g., `Hasselblad H6D-100c medium format, 80mm f/2.8 planar lens, Kodak Portra 400 film stock, directional window sidelight, subtle organic film grain` (or `Phase One IQ4 150MP 120mm f/4 Apo-Macro` for studio hardware cutouts).
3. **Layer 3 — Surface Chromatic Floor Anchor (`--bg-hex`)**:
   - Anchor the ambient shadow floor or backdrop pigment to the exact CSS background color (`--bg-hex`) of the target web section so the image edges dissolve seamlessly into the DOM canvas.

### The 7 Forbidden Image Prompt Words (Strictly Stripped)
Never include any of the following tokens in an image generation prompt:
1. `"UI background"` / `"website banner"` / `"hero image"` (causes fake buttons and garbled text to appear inside the image)
2. `"8k masterpiece"` / `"trending on artstation"` / `"hyperrealistic"` (triggers oversaturated plastic rendering)
3. `"futuristic glowing nodes"` / `"cyberpunk neon grid"`
4. `"transparent background"` / `"alpha channel"` (causes generators to draw a literal gray-and-white checkerboard pattern!)
5. `"logo"` / `"app icon"` / `"badge"` / `"emblem"` (causes generators to draw circular rings and fake bevels)

## 3. IP-as-Logo: 7 Subtractive Geometry Rules (`--mode ip-logo`)

When creating an IP mascot symbol, brand mark, or avatar that must remain recognizable at **`32×32px` and `16×16px`**, use `python scripts/media_gen.py prompt "<character>" --mode ip-logo --aspect 1:1`:

1. **4–7 Geometric Blocks Maximum**: Deconstruct the character into 4–7 bold, flat shapes.
2. **Single Species Trait**: Keep at most **1 defining biological trait** (e.g., rabbit ears OR fox tail). Omit fingers, toes, fur strands, whiskers, blush, clothing folds, and props.
3. **Strict 3-Color Semantic Ceiling**: Maximum **2 flat body color zones** + **1 muted solid background color** = **3 colors total**. Zero gradients, zero specular highlights, zero drop shadows.
4. **Zero Sharp Tips**: Every outer contour and inner seam must use generous rounded curves.
5. **Frame-Breaking Corner Composition (`85%–95%` Fill)**: Never shrink the full body into the center of the canvas. Use a `1:1` square canvas where the character rises upright from the **lower-left or lower-right corner**, occupying `85%–95%` of the frame.
6. **Prompt Hygiene**: Never use the words `"logo"`, `"icon"`, `"badge"`, or `"transparent"` in the prompt.
7. **Never Hand-Code Mascot SVGs**: Always generate via image model rather than assembling crude `<circle>`/`<polygon>` SVG primitives.

## 4. Pixel-Level `calm` Zone Verification & The 6-Step Page-Blending Law

After generating or downloading any image, run:
```bash
python scripts/media_gen.py analyze ./hero.png
```
This decodes the image into a `48×48` luminance matrix, evaluates the 5 directional zones (`left`, `right`, `top`, `bottom`, `center`) for standard deviation (`sd < 0.095`) and edge gradient (`grad < 0.025`), and outputs `best_text_overlay_zone` and `dominant_hex`.

### The 6-Step Page-Blending Law (How to Make Images Belong to the Page)
1. **Step 1 — Match Canvas Chromatic Floor**: Set the section container's `background-color` to match the image's shadow/backdrop hex (`--bg-hex`).
2. **Step 2 — Feather Image Edges (`mask-image`)**: Never leave a hard rectangular seam where an atmospheric hero photo ends. Dissolve the bottom or inner edge into the canvas:
   ```css
   -webkit-mask-image: linear-gradient(to bottom, #000 80%, transparent 100%);
   mask-image: linear-gradient(to bottom, #000 80%, transparent 100%);
   ```
3. **Step 3 — Directional Scrim Over the `calm` Text Zone Only**: Protect text legibility (`≥ 4.5:1`) with a directional `linear-gradient` over the text zone (`left`, `top`, or `bottom`), leaving the focal subject unobstructed.
4. **Step 4 — Never Bury the Raster (`buried-raster` gate)**: Never cover the entire photograph with a uniform `> 85%` opaque dark overlay that turns expensive photography into muddy wallpaper.
5. **Step 5 — Unified Color Grade Across Multi-Image Pages**: When a page contains multiple photos, apply a consistent subtle CSS filter (`filter: contrast(1.03) saturate(0.92)`) or shared SVG film-grain overlay (`feTurbulence` `baseFrequency="0.85"`, `opacity: 0.04`).
6. **Step 6 — Zero-CLS Responsive Delivery**: Always include explicit `width`, `height`, `loading="eager"`, and `fetchpriority="high"` on the hero `<img>` (and `loading="lazy"` below the fold).

# Meltday

```text
请使用本项目的 light-ui-ux skill，为虚构手作冰淇淋品牌 Meltday 设计并实现官网。

- 产品：小批次制作的冰淇淋，提供开心果、草莓、巧克力、香草等口味，以及季节限定。
- 受众：喜欢尝试新口味、愿意为好食物专程到店的年轻消费者。
- 风格：明快、圆润、鲜活。以开心果绿、樱桃红和奶白构成品牌气质，突出冰淇淋质地与真实食欲。
- 核心体验：选择杯装或甜筒，搭配单球、双球及不同口味，组合预览和价格同步更新。
- 页面至少包含：首屏、口味菜单、自由搭配、原料故事与门店信息。
- 界面语言：英文。主视口：桌面 1440 宽，同时适配手机。
```
